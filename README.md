# CSES Problem Set — C++ Solutions

A collection of my solutions to the [CSES Problem Set](https://cses.fi/problemset/), implemented in C++ as part of my journey to learn algorithms, data structures, and problem-solving techniques.

The main goal of this repository is to strengthen my understanding of algorithm design, computational complexity, and techniques that are useful for competitive programming and technical interviews.

## Goals

- Practice algorithms and data structures through problem-solving.
- Develop efficient and correct C++ implementations.
- Understand time and space complexity.
- Explore different approaches to algorithmic problems.
- Build a consistent study reference throughout my Computer Science degree.

## Problem-Solving Approach

For each problem, I aim to:

1. Understand the problem statement and constraints.
2. Identify an appropriate algorithm or data structure.
3. Implement the solution in C++.
4. Analyze time and space complexity.
5. Review mistakes and alternative approaches when useful.

The emphasis is on understanding why a solution works, rather than simply obtaining an accepted submission.
